# 旅人天气 · Travel Weather 0.11

本版主要改善当前城市定位与名称解析的可靠性，优化重开应用时的显示体验，并新增统一的天气更新时间。

作者：Leo Gorge（liu-gongjie）。主要贡献者：Codex。

## 功能更新

- **原生定位与低功耗优先**：优先使用系统融合、网络定位；必要时回退到卫星定位。支持粗略位置权限，根据坐标的新鲜度与精度选择可用结果，不进行后台持续定位。
- **双路区县名称解析**：优先使用系统 Geocoder；不可用、返回空结果、异常或超时后，调用高德坐标转换及逆地理编码。天气查询继续使用原始 GPS 坐标。
- **3 公里内静默复用位置**：已有有效地名时，新坐标距保存位置不超过 3 公里，直接沿用保存的位置和名称，不再显示“城市名称暂未更新，沿用上次结果”。
- **统一更新时间**：在“添加城市”下方显示最近一次成功获取天气的时间；全部请求失败时不推进时间，部分失败会提示。

## 问题修复与体验优化

- 针对部分手机获取当前位置容易超时的问题，增加多定位来源、近期系统位置检查、限时等待与回退处理。改善可用性，但不改变 GPS / 北斗硬件灵敏度。
- 重开应用先展示保存的位置与天气，同时请求最新数据，减少空白等待；每次打开、返回前台或手动刷新，仍更新当前位置及所有已添加城市的当前天气和五日预报。
- 将获取坐标、解析地名和查询天气分开处理。新位置名称解析失败时，仍按新坐标获取天气，显示“当前位置”，避免把旧城市名称套在新位置天气上。
- 首次失败提示调整为“无法获取当前位置和天气”；重试入口统一为“点击重新定位”；名称解析失败提示为“已获取坐标，城市名称解析失败，可重试”。
- 对系统名称解析与高德备用流程分别设置超时，避免长时间卡住；退出前台时清理定位监听。

国内城市搜索仍使用和风公开城市名录的本地快照及 Open-Meteo Geocoding（GeoNames），未改用高德城市搜索。多城市五日天气、中文输入、长按排序、主题和雨量分级图标保持原有功能。

## 安装与升级

下载附件 `TravelWeather-0.11.apk`。最低 Android 6.0（API 23）；包名 `com.travelweather.app`，versionName `0.11`，versionCode `16`。

沿用 0.1 的本地测试签名，可覆盖安装并保留城市、顺序、主题与本地缓存。自行构建且签名不同的 APK 不能直接覆盖此包。校验文件 `SHA256SUMS` 同时记录 APK 和源码归档的 SHA-256。

## 验证与已知限制

- APK 构建与签名校验通过；自动化测试已覆盖位置复用边界、系统解析成功不调用备用、系统异常 / 空结果 / 超时后切换及两路失败处理，以及定位界面和天气更新时间回归。
- Android 真机 已完成当前 APK 的覆盖安装、启动及手动刷新验证：显示区县天气，原有城市保留，刷新时间更新，未出现定位错误提示；用户本轮试用未发现新问题。
- 高德坐标转换、逆地理编码的真实接口调用均成功。上述手机测试可能使用附近缓存位置，尚未单独确认真机端到端触发高德备用链路；省电模式和跨城市移动也未完成全场景验收。
- 3 公里内可能跨越区县边界，本版仍按复用规则显示保存区县。网络、系统定位或第三方服务不可用时仍可能失败。
- “最新更新时间”是本机成功获取数据的时间，不是气象站观测时间；当前天气来自 Open-Meteo 模型的最新可用结果。

## 数据与源码

天气：Open-Meteo；国内地名：和风公开城市名录；补充地名：GeoNames；备用逆地理编码：高德。

当前 APK 按测试阶段方案内置高德 Web 服务 Key；该 Key 不进入 Git 源码和源码归档，但 APK 内的 Key 可被提取，不具备服务器端保密性。自行构建默认不内置 Key，启用备用服务需自行配置，方法见设计开发文档。源码采用 MIT License，第三方数据与服务遵循各自条款。
