# TravelWeather 0.11 开发说明

作者：Leo Gorge（liu-gongjie）；主要贡献者：Codex。

## 本版改进

1. Android 端改为原生前台定位，同时利用设备提供的融合、网络和卫星定位。根据新鲜度与精度筛选位置；手动重试请求新坐标，失败时可回退到近期可用位置。权限拒绝、系统定位关闭和超时分别提示。
2. 系统区县名称解析与天气获取分离，已有坐标时不会因区县解析失败而完全丢失天气。Android 13+ 的名称解析采用异步接口和超时。
3. 首次定位失败提示改为“无法获取当前位置和天气”。
4. 在“添加城市”下方显示最新更新时间（本机最近一次成功获取天气的时间）；全部请求失败不更新时间，部分失败会提示。

仍保留每次启动、返回前台、手动刷新更新全部城市的实时天气及预报；同区县复用位置记录。没有后台持续定位，不要求关闭省电模式或申请电池白名单。

## 版本与安装

包名 `com.travelweather.app`；versionName `0.11`，versionCode `16`。沿用 0.1 测试签名，可覆盖升级，保留原城市、主题和缓存。0.1 的 APK 与 `v0.1` 标签不变；0.11 尚未替换 0.1 Release。

## 验证范围

浏览器自动测试覆盖原生接口交互、定位失败重试、名称解析失败但天气成功、位置缓存、天气刷新、更新时间持久化与失败不推进，以及城市搜索、输入法、拖动排序、雨量图标。Android 模拟器中已验证安装启动、原生获取注入的卫星坐标，以及名称解析失败时仍显示真实联网天气。

三星 S26+ 首轮实测暴露了系统定位超时问题；当前已调整为明确高精度请求、45 秒前台等待与近期系统位置检查，仍需验证独立冷启动及省电模式，不能宣称已解决该机型所有定位问题。卫星硬件灵敏度和系统电量限制不能由应用强制改变。建议真机分别在正常 / 省电模式下验证首次启动、反复重开、手动重新定位、室内网络定位、室外卫星定位以及关闭 / 恢复系统定位后的重试。
