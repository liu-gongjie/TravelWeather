# 旅人天气 · Travel Weather 0.13

发布日期：2026-10-01。

## 界面改进

- 页面最下面的应用名称和数据来源两行文字移入“关于/about”窗口，页底仅保留入口按钮。
- 关于窗口采用紧凑的居中布局，最大宽度 320px，高度随内容自适应，支持浅色与深色主题。
- 点击右上角关闭按钮、窗口外遮罩或系统返回键即可关闭。

窗口文字全部居中，内容五行：

