# 0.12 开发中

## 更新

- 刷新时右上角箭头连续旋转，保持正常颜色；位置、当前天气和五日预报刷新结束后停止，失败也会停止并显示相应提示。
- 页面顶部单指向下拉，达到阈值后松开刷新，与右上角按钮共用刷新流程；防止重复刷新，保留长按城市卡片排序。短拉、取消、弹窗内操作和离开前台不触发。
- 系统 Geocoder 优先，高德备用接口改为 HTTPS 服务端代理。Key 不再进入 APK；只在服务器保存。代理部署尚待服务器连接信息和可信 HTTPS 地址。
