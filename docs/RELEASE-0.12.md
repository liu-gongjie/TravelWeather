# 0.12 开发中

## 更新

- 取消亮屏、解锁及从其他应用切回时的自动刷新；保留启动、右上角按钮和下拉刷新。

- 刷新图标采用圆心对齐的 SVG，旋转中心与白色按钮圆心重合，消除文字字形偏心。刷新时右上角箭头连续旋转，保持正常颜色；位置、当前天气和五日预报刷新结束后停止，失败也会停止并显示相应提示。
- 页面顶部单指向下拉，达到阈值后松开刷新，与右上角按钮共用刷新流程；防止重复刷新，保留长按城市卡片排序。短拉、取消、弹窗内操作和离开前台不触发。
- 系统 Geocoder 优先，高德备用接口改为 HTTPS 服务端代理。Key 不再进入 APK；只在服务器保存。代理已部署至腾讯云服务器，使用可信 IP HTTPS 证书。

- 定位请求等待页面恢复前台并获得窗口焦点后启动，避免启动时按后台请求限流消耗等待时间；重复恢复不会重复注册。权限拒绝及时结束。

## 版本记录

原 `v0.11` 发布标签保留。开发基线为 `0a30bc7`，另有 `backup/pre-0.12-20260930` 标签和仓库外的完整 Git bundle，0.12 在 `develop/0.12` 分支开发。versionName `0.12`、versionCode `17`，沿用原签名。

## 验证

刷新动画及下拉手势测试、代理坐标参数/转换顺序/返回字段单元测试通过，APK 构建与签名验证通过。云端代理真实长沙、广州地址解析、TLS 校验、非法参数处理及证书自动续期演练已验证。测试 APK 已接入 HTTPS 代理并确认不包含高德 Key；真机完整链路尚未验收，不作为正式 Release 发布。
