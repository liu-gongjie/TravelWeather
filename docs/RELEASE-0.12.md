# 旅人天气 0.12 Release 说明

更新日期：2026-10-01。以下描述0.12 版相对 0.11 的功能与修复。

## 功能更新

- 调整顶部当前位置天气摘要：天气文字置于图案正下方并缩小图文间距，图案与文字组成左侧一组，右侧温度垂直居中；城市卡片布局保持不变。

- 刷新时右上角箭头绕白色按钮圆心旋转，完成或失败后停止；采用较短圆弧、纤细描边和略淡颜色，每圈 1.7 秒。
- 增加下拉刷新：页面位于顶部时向下拉达到阈值，松手后刷新，与右上角按钮共用流程。短拉、取消、弹窗及长按排序不触发刷新。
- 明确刷新时机：应用启动、点击刷新按钮或下拉刷新时更新当前位置及所有已添加城市的当前天气与五日预报；关屏后亮屏、解锁及从其他应用切回不再自动刷新。
- 添加城市入口下方的时间文案改为“天气更新时间：”。该时间是本机成功获取天气数据的时间，并非气象站观测时间；部分城市更新失败时提供提示。
- 高德备用逆地理编码改为自建 HTTPS 代理，Key 保存在服务器，源码及 0.12 APK 不包含 Key。城市搜索仍使用原有和风公开城市名录及 GeoNames。

## 修复

- 修复刷新箭头旋转偏心的问题，使其旋转中心与按钮圆心一致。
- 定位请求等待应用进入前台并获得窗口焦点后启动，避免启动阶段被后台限流；重复恢复不会重复注册，权限拒绝及时结束。
- 修复超过 2 公里后名称解析仍为同一区县却保留旧锚点的问题：解析成功后保存本次新坐标，并按新坐标更新天气，避免后续在同一位置反复解析。
- 保留 2 公里内有效名称静默复用的规则，不调用系统 Geocoder 或高德；天气仍每次按新坐标刷新，名称锚点保持不变。无有效名称或超出范围时，先使用系统 Geocoder，失败或超时后调用高德代理。

## 验证与适用范围

- 刷新动画、下拉手势、启动和手动刷新、亮屏及切回前台不刷新、同区新锚点保存及后续名称复用的回归测试通过；APK 构建与签名验证通过。
- 真机定位及刷新测试已进行，实际高德代理备用链路调用已确认；最终锚点修复通过回归测试，测试 APK 已更新到真机。
- 云端代理的坐标校验、转换顺序、返回字段、真实地址解析、TLS、限流、非法参数处理及证书自动续期演练已验证。
- 普通测试版不包含临时计时日志及 WebView 远程调试开关。临时诊断版已被普通版替换。
- 首次或超出 2 公里需要重新解析名称时，系统 Geocoder 超时及备用服务网络请求仍可能增加等待时间。已有内容会先显示；天气来自 Open-Meteo 的最新可用模型结果。

## 版本与兼容性

versionName `0.12`、versionCode `18`，使用新的正式发布签名；此前旧签名测试版本需要先卸载再安装，后续新签名版本可覆盖升级。原 `v0.11` 发布标签和备份保留；0.12 在 `develop/0.12` 分支维护。发布标签为 `v0.12`，Release 提供 `TravelWeather-0.12.apk` 及 `SHA256SUMS`；普通发布包不含临时诊断功能。

## 安全签名更新

采用新的正式发布私钥和强随机口令，versionCode 为 18。签名口令由 macOS 钥匙串保存，构建脚本不再硬编码口令或自动生成替代密钥。此前旧签名测试包需先卸载（会清除应用内城市和设置）；后续使用此正式签名的升级可覆盖安装。
